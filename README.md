# TerminalGame
I've been having a bit of fun with C++ 

When I originally started making TerminalGame, I wanted to create game that would combine the core mechanics of Civ VI with a city building mechanic similar to Cities: skylines. Coming back to the project almost 4 years later, I've played a lot more strategy games and my outlook on this project has changed quite a lot. 

My main goal is to create a game that has so many in-depth mechanics that the game becomes functionally unplayable to anyone without a PhD in micromanagement and a stockpile of tylenol.
